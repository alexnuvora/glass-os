# GlassOS upstream feature integration
## Folio (MIT)
https://github.com/McCal-Codes/folio
Folio is a Kotlin/Jetpack Compose implementation; GlassOS currently uses native Java Views. Folio's MIT source provides a candidate for a future full migration. No Folio sources have been copied into GlassOS in this release.
Feature patterns independently implemented here: multiple home pages with page indicators and horizontal navigation; persistent per-page app slots; contextual editing and folders; searchable app library; launcher-local status island; controls and settings pages.
Folio features not yet ported: live Android AppWidgetHost widgets, app cutout-aware overlay via accessibility, notification-driven island activities, jiggle drag and drop, side bar, focus rules, smart stacks and comprehensive customisation sheets.
## QWEA0 Liquid-Glass-Android (MIT)
https://github.com/QWEA0/Liquid-Glass-Android
Recommended native View rendering dependency. Requires verified integration / device-level build before shipping. GlassOS currently uses its local wallpaper sampling renderer.
