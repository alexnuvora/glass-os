# GlassOS Launcher

Independent iOS-inspired Android launcher (non-root). Includes two editable home pages, app search, folders, widgets (battery/clock/date), dock, local status island, Control Centre and settings.

The launcher does not replace Samsung system UI. See UPSTREAM-INTEGRATION.md for upstream design architecture and outstanding ports.
