# Vape Mart — Commerce Showcase

Independent concept demonstration for Vape Mart Ltd. Not affiliated with or approved by Vape Mart Ltd.

## Preview
Open `index.html` in a browser, or deploy the repository as a static website on Vercel (Framework Preset: Other; no build command).

## Features
Sample catalogue of 12 fictional general-purpose accessories, search/filtering, cart, wishlist, wholesale pricing examples, and simulated checkout.

## Important
All products, pricing and trade terms are illustrative. This is NOT a live commerce system. No payment processing, genuine stock, wholesale verification or order fulfilment is connected. Review UK vaping-sales and advertising requirements before incorporating real vaping products.
